# How to Read This Repository as a BA

This repository is intentionally arranged to show the chain of Business Analysis artifacts.

| BA question | Artifact |
|---|---|
| Why does the business need the system? | Business Problem / Objectives |
| What is included or excluded? | Project Scope |
| Who participates? | Stakeholders / Process Actors |
| How does work flow today/in the designed ERP process? | Process Specifications / BPMN references |
| What must the business achieve? | Business Requirements |
| What must the system support? | Functional Requirements |
| What conditions constrain the process/data? | Business Rules |
| How can requirements be expressed for delivery? | User Stories + Acceptance Criteria |
| How are artifacts connected? | RTM |
| How can business users validate behavior? | UAT Cases |

The source report does not provide a formal AS-IS/TO-BE analysis, explicit non-functional requirements, or a complete production-grade security/permission specification. Those are therefore not fabricated here.
